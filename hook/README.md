# Нативная интеграция PvZ

`pvzmp-loader.exe` запускает оригинальную Steam-оболочку и загружает
`pvzmp-hook.dll` в её дочерний игровой процесс. Текущие хуки меню рассчитаны
на `pvzgame.exe` из PvZWidescreenForSteam 1.0. Перед установкой проверяются
известные адреса виртуальных методов; для другой сборки хуки не ставятся.

Кнопка и панель рисуются штатным движком SexyAppFramework внутри игрового
кадра. Сетевой поток Winsock обслуживает LAN-лобби; игровое поле ещё не подключено.
См. [оформление меню](../NATIVE_MENU.md) и [подключение по LAN](../LAN.md).

Сборка из корня игры:

```bash
./multiplayer/hook/build.sh
```

Нужны Clang, lld-link, заголовки Wine и Windows x86 import libraries Wine.
Получаются PE32 x86 DLL и загрузчик, запускаемые через Proton.

В параметрах запуска оригинальной записи PvZ (AppID 3590) в Steam:

```text
"/ПОЛНЫЙ/ПУТЬ/Plants Vs Zombies/multiplayer/hook/steam-launch.sh" %command%
```

Скрипт сохраняет аргументы Proton, заменяя только EXE на загрузчик мода.
Добавлять загрузчик отдельной сторонней игрой не нужно. Расположение файлов
важно: оригинальная игра должна находиться на два уровня выше загрузчика,
DLL — рядом с ним. Файл `multiplayer/wide-menu-enabled` включает хуки при
установленной widescreen-основе. Чтобы полностью вернуть обычную цепочку
запуска, удалите параметр запуска из Steam.

Логи: `pvzmp-hook.log` и `pvzmp-hook.log.menu` в корне игры.
