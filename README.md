# PvZ LAN multiplayer — прототип правил

Этот прототип написан на C++20 и запускается рядом с установленной Steam-версией PvZ. Он **не изменяет**
`PlantsVsZombies.exe` и сам по себе **не интегрируется в оригинальную игру**.
Это отдельная браузерная игровая сцена для проверки сетевого цикла и правил перед
переносом в нативный мод.

## Запуск

На компьютере хоста:

```bash
./multiplayer/run.sh
```

Нужен компилятор `g++` с поддержкой C++20. Скрипт собирает сервер и напечатает два адреса. Хост открывает адрес `127.0.0.1` и выбирает
«Играть за растения». Другой игрок в той же LAN сети открывает локальный
`multiplayer/client.html`, вводит IP хоста и порт, затем выбирает «Играть за зомби».
Порт автоматически выбирается
из свободных. Если указанный IP оказался неправильным, используйте LAN IP хоста
с напечатанным портом. Можно задать порт вручную: `./multiplayer/run.sh --port 8097`.
На Windows можно собрать `native.cpp` через MSVC (C++20, `Ws2_32.lib`) и запустить
полученный `pvzmp.exe` из каталога `multiplayer`.

## Правила текущего прототипа

- Растения получают солнце постепенно и могут ставить горохострел, подсолнух и орех.
- Зомби получают мозги за съеденные растения. Они могут вручную посылать три вида
  зомби, строить обычные могилы для автоматического появления зомби и фермы для
  пассивного дохода мозгов.
- Растения побеждают, уничтожив выстрелами все пять особых могил справа.
- Зомби побеждают, доведя любого зомби до левого края поля.
- Матч вычисляется у хоста; действия клиента проходят проверку стоимости, роли,
  доступной клетки и текущего этапа. Клиент получает готовое состояние поля.

Нативная кнопка и LAN-лобби теперь реализованы отдельно в `hook/` для
widescreen-сборки. См. [LAN.md](LAN.md). Следующий этап — перенос правил
на объекты `Board` и синхронизация игрового поля.
