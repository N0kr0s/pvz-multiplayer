# Графика Multiplayer

- `multiplayer-stone.png`: прозрачная PNG-подложка, сгенерированная ImageGen по
  референсам оригинальных SURVIVAL и PUZZLE. Используется вторая версия:
  грубая плоская серо-фиолетовая поверхность без жёлтого блика. Alpha сохранена.
- `multiplayer-label.png`: отдельный сгенерированный слой тяжёлых неровных
  чёрных букв с клиновидными засечками, по тем же оригинальным референсам.
  Отрисовывается поверх камня с полями, в области 222x64 игровых пикселя.
  Старый шрифтовой инструмент build_menu_lettering.py для этой версии не нужен.

Игра загружает обе текстуры через ResourceManager и кэширует их. Hover не
подменяет PNG: подложка получает дополнительный аддитивный проход на 48/255.
Текст рисуется поверх и не осветляется. При нажатии оба слоя смещаются на 1 пиксель.

Первые варианты обоих изображений сохранены в backups/menu-art-v1.

- `menu.patch`: проверяемые XOR-разности двух записей исходного widescreen PAK:
  скомпилированная анимация меню и XML регистрации PNG. Установщик требует
  соответствующий исходный PAK; другие записи не меняются. Полный PAK не включён.
